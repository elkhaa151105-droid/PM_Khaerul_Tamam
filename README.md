## Temuan Utama

- Jenis masalah ML dapat dibedakan menjadi klasifikasi dan regresi. Klasifikasi digunakan jika hasil prediksi berupa kategori, seperti Ya/Tidak atau Murah/Mahal. Regresi digunakan jika hasil prediksi berupa angka, seperti harga rumah atau jumlah pengunjung.
